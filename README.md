# DF1 — API для управления библиотекой

## Тэги

DRF, Django, Git, JWT, ORM, OpenAPIDocs, PEP8, Permissions, PostgreSQL, Readme, Serializers, Viewset/Generic, Docker,
Docker-Compose

## Описание проекта

Проект реализует REST API для управления библиотекой.
API предоставляет возможности для работы с книгами, авторами и пользователями, а также для отслеживания выдачи книг.
Использован Django Rest Framework (DRF) для построения API.

## Цели

+ Реализовать функционал управления библиотекой через API.
+ Аутентификация и авторизация пользователей с использованием JWT.
+ Управление книгами и авторами.
+ Функционал учёта выдачи и возврата книг.

## Функционал API

### Управление книгами

+ Создание, редактирование, удаление книг.
+ Получение списка всех книг.
+ Поиск книг по названию, автору, жанру и другим параметрам.

### Управление авторами

+ Создание, редактирование, удаление авторов.
+ Получение списка авторов.

### Управление пользователями

+ Регистрация и авторизация.
+ Получение информации о пользователях.

### Учёт выдачи книг

- Запись информации о выдаче книги пользователю.
- Отслеживание состояния возврата книги.

## Технические требования

+ Использовать Django и Django Rest Framework (DRF).
+ База данных — PostgreSQL.
+ Контейнеризация через Docker и Docker Compose.
+ API-документация реализована по стандарту OpenAPI (автогенерация).
+ Соблюдать стандарты PEP8.
+ Хранение кода в удалённом Git репозитории.

## Установка и запуск

1. Склонировать репозиторий:
    ```
    bash
    git clone https://github.com/Alexandr-Celestial/Library_API.git
    cd Library_API
    ```
2. Создать `.env` файл с необходимыми переменными окружения (пример в .env.example).
3. Запустить Docker Compose для поднятия контейнеров:
    ```
    bash
    docker compose up -d --build
    ```
4. Применить миграции:
    ```
    bash
    docker compose exec web python manage.py migrate
    ```
5. Доступ к API будет по адресу:
    ```
    text[
    http://localhost:8000/api/]()
    ```
6. Документация API:
    ```
    text
    http://localhost:8000/api/docs/
    ```
    (автоматически сгенерирована по стандарту OpenAPI)

## Структура проекта
* `authors/` — приложение для управления авторами.
* `books/` — приложение для управления книгами.
* `users/` — приложение для управления пользователями и аутентификацией.
* `lending/` — приложение для учёта выдачи и возврата книг.
* `Dockerfile` — описание образа для контейнеризации.
* `docker-compose.yml` — описание сервисов для Docker Compose.
* `README.md` — данный файл с описанием проекта.

## Качество кода
* Код следует стандартам PEP8.
* Используются сериализаторы DRF, видавсеты (viewsets) и permission-классы.
* Аутентификация реализована с помощью JWT токенов.
* Комментарии и документация в коде для лучшего понимания логики.
